# Roadmap

## Phase 1 — MVP ✅
- [x] Premium landing page (6 sections, glassmorphism, dark/light mode)
- [x] Magic-link authentication (signup, login, sessions, logout)
- [x] Brand Discovery Wizard (8 steps, auto-save, brand inspirations)
- [x] Projects API (CRUD + delete)
- [x] AI Strategy Engine (GPT-4o prompts, 9-section parsing, polling)
- [x] Premium strategy results page (scroll-spy TOC, DNA score rings, print-ready)
- [x] Dashboard (project list, status badges, delete, empty states)
- [x] Modular architecture refactor

## Phase 2 — Stripe Payments (next)
- Stripe Checkout integration for paid strategies
- Pricing tiers: $99 (Basic), $199 (Pro), $299 (Enterprise)
- Payment success → unlock strategy generation
- Free tier: 1 strategy preview (limited sections)
- Billing portal, invoices

## Phase 3 — Logo Concepts
- AI-generated logo concepts based on brand strategy
- Multiple style directions (3–5 concepts per strategy)
- SVG output with color palette
- Logo refinement UI

## Phase 4 — Brandbook
- Complete brand identity document
- Logo usage guidelines
- Color system + typography specs
- Visual examples, mockups
- PDF export

## Phase 5 — Website Generator
- AI-generated landing page based on brand strategy
- Component-based page builder
- Copy + design generated from brand voice + creative direction
- Hosting/publishing integration

## Phase 6 — Marketing Assets & Exports
- Social media templates
- Business card designs
- Email signature generator
- Full PDF export of all assets
- Brand portal with asset library
